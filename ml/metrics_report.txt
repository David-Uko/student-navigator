======================================================================
DEPLOYED MODEL: Ridge Regression
======================================================================
Selected for deployment because its parameters (an intercept plus one coefficient per feature) port exactly into the TypeScript server function that serves predictions in production, and because L2 regularisation keeps its coefficients stable despite correlated input features — which matters because those same coefficients are shown to lecturers as the explanation for each prediction. Random Forest and Gradient Boosting were evaluated (above) and are not categorically worse, but porting an ensemble of trees into the existing Python-free serving architecture would add substantial complexity for a final-year project without a clear accuracy justification here.

Fitted equation:
  predicted_score = -0.21
    + (0.1501 * previous_semester_average)
    + (-2.3203 * previous_failed_courses)
    + (0.1290 * attendance_rate)
    + (0.2383 * avg_test_score)
    + (0.1117 * study_habits_score)
    + (0.0212 * assignment_average)
    + (0.1756 * assignment_completion_rate)
    + (-0.0503 * assignment_late_rate)
    + (0.5239 * performance_change)
    + (1.9150 * engagement_score)
    + (2.7689 * lms_activity_score)
    + (-0.1535 * course_load)
    + (-0.1210 * weeks_remaining)

Held-out test performance:
  R^2   = 0.8685
  MAE   = 4.37 points
  RMSE  = 5.61 points
  Risk-band accuracy = 87.5%
  At Risk recall = 0.71 (71% of genuinely at-risk students in the test set were correctly flagged)

Limitations:
  - Trained on a synthetic dataset (see generate_dataset.py), not real institutional records. Course load and weeks-remaining were generated independently of the outcome, so their near-zero coefficients reflect the synthetic data design, not a claim that these factors are unimportant in reality.
  - At Risk is the smallest, hardest class to predict (fewest training examples); its recall is the single most important number in this report for an early-warning system and should be monitored closely if the model is retrained on real data.
